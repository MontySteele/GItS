## Patterns

1. **The four core keyword tips and the Bomb pile badge are rules essays kept alive only by name-carried lint exceptions.** `BombKey`, `SetOffKey`, `MineKey` and the entire `ProtoBombPower` badge family (static face + 33-row smart grid) are all 1.3×–3.3× their ceilings. Each grew through a long chain of one-clause-at-a-time "EB-" amendments (a seat misreads something → add a sentence), and none of the amendment commits revisited the whole tip once it stopped fitting — the lint's own exception reasons still quote character counts ("133 of 135") that are stale by 50–300 characters against the current source. Worth a holistic rewrite pass rather than another clause.

2. **"Instead" chains and passive voice recur across the same handful of cards** — `proto_ko_coven_errand`, `proto_ko_team_effort` ("instead"); `proto_ko_return_to_sender`, `proto_ko_big_bounce` (passive "is placed"/"is dealt"). Both are named explicitly in the F5 criterion, and both are avoidable with a straightforward active-voice rewrite ("Place it on ALL enemies instead" → name the actor; "damage ... is placed" → "place the damage").

3. **Redundant same-turn framing** — `proto_ko_sit_tight`, `proto_ko_patience_klee`, `proto_ko_grounded`, `proto_ko_wait_for_it` all stack two temporal phrases in one sentence ("at the end of this turn... this turn," "your turn... last turn"). These read as a template that was copy-pasted per-trigger without re-checking whether the second "turn" reference is load-bearing.

4. **Badge text quietly drops a rule its own card states.** `proto_ko_second_surprise`'s card says "rounded down"; the Power it grants (read live, once the card is gone) does not. Same shape, smaller stakes, as `proto_ko_hair_trigger`'s singular/plural slip (pattern 5).

5. **"Set off" as an event is sometimes written as prose instead of the golded keyword.** `proto_ko_vermillion_pact` (and its identical-text power badge) writes "the Attack that set it off," against the house's own documented rule that the EVENT is always "goes off" in prose and "Set off" (capitalized, gold) is reserved for the deliberate action.

6. **"Additional" is the house word for bonus damage (36:2 in the base game per text-conventions); `proto_ko_fish_fry`'s "5 more" is the one holdout** among Sizzle, Run Away!, and Catalytic Converter's badge, all of which say "additional."
