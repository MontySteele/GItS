# Klee Balance suite 5 and the base control, 2026-10-08

Suite 5 ran on `klee-next` 063e1b40 (0.2.4556+next). That build is the design review as ruled
(`review/active/klee-design-review-2026-10-08.md`):
- Bombs grow 2 a turn.
- A fight opens with 3 Sparks.
- Drafted placers are +2.
- Fire! Fire! and Blasting Spree are in; Playdate and Pop! are out.

It used the same five seeds and seats as suites 2 to 4: A0, one Sonnet seat per act. The same night,
the five base characters were re-run on their own seeds with the same seats and the same page
generation (the **control**).

**How this is graded.** Every comparison is by run instance, not by clock window:
- **base:** the five counted runs of 10-05 (`20261005-1055xx`, Regent `20261005-113940`);
- **control:** tonight's five (`20261008-004850`, `-004901`, `-010351`, `-010845`, `-011903`);
- **suite 5:** `20261007-2357xx`.

The old base window (10-05 before 16:50) also held an off-seed run, a stopped attempt and doubled
rows (project review of 2026-10-08, finding 1). Fight numbers are means over fights from
`tools/telemetry_report.load_fights`, deduplicated on run instance, fight and seat.

**Matched seeds.** A Klee run that dies in act 2 has no act-3 fights. Pooled act-3 numbers then
compare her three surviving seeds against all five base seeds. The first version of this record did
that, and it read a gap that is mostly seed mix (below). The tables therefore compare each act only
on the seeds where both sides have fights.
- This is a re-cut made after the run, not the pre-registered read.
- Pick 3 registers it for suite 6 on.

**Instrument note.** The act-1 seats ran the page from a stale main checkout. Where no Bomb tip was
on screen, the page said "grows 4" and "1 Spark". Every seat saw the board grow by 2 and trusted the
board. From act 2 the page ran from the `klee-next` worktree, which split the lanes' state (no action
cap in act 2, words store restarted). Telemetry is unaffected. The fix is merged (#971).
