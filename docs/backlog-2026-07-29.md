#### Routed here by the Understudy Phase-0 measurement (2026-08-04, R93/R96)

Four observations from one nine-floor run driven through the real game. All
four are notes in a queue, not open work: **nothing in `tier0/pilot/`,
`tier05/` or any sheet was touched by the sprint that filed them.** Each was
made by comparing the sim's own policy against a human's play at the same
state, which is the only reason a nine-floor sample is worth writing down —
the run is not the evidence, the *mechanism it exposed* is. Full context:
`docs/understudy-phase0-report.md`; the ruling that routed them:
`tier0/DECISIONS.md` R93 (item A) and R96 (items B–D).

- **[pilot-improvement] The block-panic rung never asks whether the Block on
  offer can matter.** `tier0/pilot/policy.py`'s rung fires on the ratio of
  incoming to remaining HP alone: if it trips, it plays the biggest blocker in
  hand, full stop. It never asks (a) whether that Block can meaningfully dent
  the incoming, or (b) whether killing an enemy would remove more incoming
  than the Block prevents. Observed board: **39 incoming, a Frail-reduced 4
  Block available, and a 25 HP enemy that exactly 25 damage in hand could
  kill** — the rung asked for the 4 Block on five consecutive decisions, while
  the kill deleted 15 of the 39 permanently. Understudy's `policy_v1` gates the
  rung on both questions (R93 #2, `understudy/policy_v1.py::_gated_ladder`), so
  a worked implementation and a red test exist to copy from. **Nobody changes
  `tier0/pilot/policy.py` for this now** — it would move every tier-0.5 number
  in the repo on one observation, and it is a scheduling decision like the
  drafter repricing above.
- **[DRAFTER 13 — regression fixture] `score_offer` returns exactly 0.0 for
  The Gallery Stirs**, a Power reading "the first time you spend Encore each
  turn, draw 1 card. Fanfare Cap +5", offered to a deck whose three Salon
  members spend Encore every single turn. This is almost certainly one of the
  42-of-56 zero-priced ops in the entry above, **observed in the wild rather
  than enumerated in a table** — which makes it the cheapest available
  acceptance test for the repricing. **Acceptance form, per R96: DRAFTER 13 is
  not done while The Gallery Stirs scores 0.0 at offer.**
- **[`_static_power` repricing session — exhibit] `score_offer` prices
  Vulnerable as a flat debuff** (`amount * 2` through `_static_power`), so it
  cannot see a multiplier applied to an engine that is already producing
  damage every turn. Observed at a floor-4 draft with two Salon members
  already ticking: Usher the Waves scored 7.58, Charlotte 1.83. Second exhibit
  for the session that already has one.
- **[reactions-promotion session] `tier0.pilot.policy._reaction_value` has no
  defensive term.** Frozen halves an incoming attack; the pilot prices
  reactions purely as expected damage (`PILOT_REACTION_TRIGGER_VALUE`), so the
  defensive half is invisible to it. Observed: a Cryo-into-Hydro reaction
  survived a telegraphed 24 for roughly zero cost while the pilot wanted 5
  Block. This is **"reactions are weather, not strategy" appearing inside the
  pilot's own head** — a third independent sighting of the same disease, and
  the first one from inside the code rather than from a play report.
